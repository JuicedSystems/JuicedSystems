# Dylan Smith

**Founder-engineer building AI-native commerce tools · Orange County, CA**

I've run Juiced Systems, a consumer electronics business, for about 15 years. Today I build and ship the software I wish I'd had as an operator: Shopify apps, MCP servers, and SaaS products on the Claude API. I work mostly in TypeScript, Next.js, and PostgreSQL, from schema through deployment.

**Open to roles:** full-stack, AI product, or founding engineer. More at [dielawn.com](https://dielawn.com).
